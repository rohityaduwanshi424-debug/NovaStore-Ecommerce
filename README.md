# 🛒 NovaStore - Modern E-commerce Website

A modern responsive E-commerce website built using HTML, CSS and JavaScript.

## ✨ Features

- Responsive Design
- Shopping Cart
- Wishlist
- Product Search
- Product Filter
- Product Sorting
- Quick View Modal
- Dark Mode
- Toast Notifications
- Loader Animation
- Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
